博客改造实录：终端极简风设计系统的实现

2026-10-20·4 min read
#设计#CSS#Next.js

你现在看到的这个终端极简风博客，是我自己动手改造的。这篇是改造实录：设计思路为什么这样定，几个关键的技术实现细节，以及砍掉了哪些"看起来很酷"的想法。

设计定位：优雅的终端，而不是复古的终端#

提到"终端风"很容易滑向两个俗套：满屏荧光绿加扫描线特效，或者 CRT 显示器的怀旧滤镜。我想要的都不是。

我的定位是：用终端的语法（$、://、##），讲现代排版的语言。具体来说：

  • 终端元素只出现在"仪式性"位置：logo（mydxx://blog）、命令提示（$ whoami）、标题前缀（## ）
  • 骨架是克制的排版系统：大量留白、细边框、单色强调，接近一份精心排版的杂志
  • 全站只有一个强调色——终端绿。信息层级靠字重、字号和颜色深浅表达，不靠花色

这个思路类似一个原则：主题感来自语法，不来自特效。

设计令牌：先定变量，再写页面#

全部颜色收敛成 CSS 变量，亮暗主题各一组：

:root {
  --paper: #f7f6f2;   /* 暖纸白，比纯白柔和 */
  --ink: #1d1f1c;     /* 带一点绿意的近黑 */
  --muted: #70766f;   /* 次要文字 */
  --line: #e3e1d8;    /* 细分隔线 */
  --term: #047857;    /* 终端绿：亮色下用深一档 */
}

.dark {
  --paper: #0b0e0c;   /* 近黑，带一丝绿意 */
  --ink: #d6dcd4;
  --term: #3ddc97;    /* 暗色下亮绿 */
}

两个颜色决策值得说明：

  1. 亮色背景不是纯白，暗色背景不是纯黑。#f7f6f2 和 #0b0e0c 这种"各偏一点"的色值，长时间阅读舒服得多，也让两个主题看起来是一套系统的两个状态，而不是白底黑字和黑底白字的简单反转
  2. 绿色在两种主题下用不同明度。同一个绿色在纸白上是刺眼的，在近黑上是不够亮的。强调色随主题调整，层级关系才稳定

中文排版的三个细节#

中文 web 排版和英文不同，这几处是调出来的：

行高与字距：正文 line-height: 2、letter-spacing: 0.01em。中文方块字本身密度高，2.0 的行高是阅读长文舒适度的下限。

列表符号：默认圆点在中文里存在感弱，换成 ▸ 并染上强调色——既是终端味，也是视觉锚点：

.prose ul > li::before {
  content: "▸";
  color: var(--term);
}

不使用斜体：中文没有斜体字形，浏览器对中文做伪斜体是强行倾斜，很难看。引用块坚决不用 font-style: italic，改用左边框 + 颜色变浅表达。

标题的 ## 前缀#

终端语法最点睛的一处，实现只需要伪元素：

.prose h2::before {
  content: "## ";
  color: var(--term);
  font-family: var(--font-mono);
  font-size: 0.8em;
}

## 是 Markdown 源码里标题本来的样子——读者在渲染页看到源码形态的提示符，这个"泄漏"是刻意的。它同时解决了另一个问题：中文标题和英文标题的视觉重量不同，前缀给了每级标题一个统一的"节拍器"。

防主题闪烁：一行内联脚本#

暗色模式下刷新页面闪一下白屏，是所有 class 切换主题方案的通病：React 还没水合，CSS 里默认的亮色已经渲染了。解法是在 <head> 里塞一段首帧渲染前执行的内联脚本：

<script>
  (function () {
    var stored = localStorage.getItem("theme");
    var dark = stored === "dark" ||
      (!stored && matchMedia("(prefers-color-scheme: dark)").matches);
    document.documentElement.classList.toggle("dark", dark);
  })();
</script>

关键是脚本位置在 <body> 之前、且不依赖任何框架生命周期。React 水合后接管状态，suppressHydrationWarning 消除 class 不一致的警告。

砍掉的东西#

  • 打字机 JS 动画：hero 的 whoami 后面只留一个 CSS 闪烁光标。逐字打印要 JS 参与，收益配不上复杂度
  • 霓虹发光、扫描线：加了三处就删了。终端的克制感一叠加特效就崩
  • 代码块标题栏 mac 圆点：太常见了，而且和"我"没有关系

改版全程最大的感受：好的设计系统不是加出来的，是减到最后剩下的那个骨架。终端风尤其如此——它本身就是一门关于少即是多的美学。
